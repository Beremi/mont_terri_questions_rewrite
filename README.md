# Mont Terri Question Rewrite

This folder contains a Markdown copy of the reorganized Mont Terri CD-A / OGS question document.

Source Google Doc: https://docs.google.com/document/d/17VoCNMqSXFgG_cg6Of5MzQt0FKggJiOiswzYVtzDfsc

Files:

- `mont_terri_questions_reorganized.md`: the rewritten question structure exported from the Google Doc, with source-reference anchors removed.
- `AGENTS.md`: local agent instructions for writing and revising text in Michal Beres's scientific style.
- `docs/agent_writing_workflow.md`: embedded fallback workflow derived from `Beremi/style_guide`.
- `docs/text_requirements.md`: bullet-point requirements collected from the requested rewrite passes.
- `paper/`: LaTeX chapter and generated PDF for the OGS model, material fields, outputs, and model-facing questions.

The content is organized around OGS model structure, material fields, and measurement streams.
