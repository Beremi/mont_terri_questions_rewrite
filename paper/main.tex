\begin{abstract}
This report records the CD-A Niche 4 model in two layers.  The first layer is the
mathematical Thermo--Richards--Mechanics model: physical setting, unknowns,
constitutive assumptions, governing equations, boundary data, and initial state.
The second layer is the OGS realization of the same model: project-file blocks,
mesh fields, XML parameters, output arrays, and observation-facing quantities.
This separation is deliberate.  It lets us discuss the model as a scientific object
before we decide which material fields, boundary curves, and measurement operators
are safe to release for inversion or validation.  We use the report as a shared
team state-of-knowledge document and as an expert-facing map of the questions that
still require provider, measurement, or modelling decisions.
\end{abstract}
